# Online Reservation System

## Java Development Internship – Task 1

### Project Overview
The Online Reservation System is a Java Swing desktop application connected to a MySQL database using JDBC. It allows users to log in, book train tickets, view booking details, and cancel reservations using a unique PNR number.

### Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- Eclipse IDE

### Features
- User Login
- Train details lookup
- Ticket reservation
- Unique PNR generation
- Booking confirmation
- Ticket cancellation using PNR
- Input validation
- Database connectivity

### Project Files
- `DBConnection.java` – Database connection
- `LoginFrame.java` – Login screen
- `MainMenu.java` – Main dashboard
- `ReservationFrame.java` – Ticket booking
- `CancellationFrame.java` – Ticket cancellation
- `TestConnection.java` – Database connection testing

### Setup
1. Install Java and Eclipse IDE.
2. Install MySQL and create the required database and tables.
3. Configure the database credentials in `DBConnection.java`.
4. Add the MySQL JDBC
 driver to the project build path.
5. Run `LoginFrame.java` from Eclipse.
